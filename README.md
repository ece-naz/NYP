# 👨‍🍳 Gelişmiş AI Yemek Asistanı (Web)

Bu proje, elinizdeki malzemeleri (metin veya fotoğraf olarak) analiz ederek size profesyonel yemek tarifleri sunan modern bir web uygulamasıdır. Orijinal Python/Gradio uygulamasının yüksek performanslı ve premium tasarımlı HTML/JS versiyonudur.

## 🌟 Özellikler

- **Yapay Zeka Entegrasyonu**: Google Gemini API kullanarak gerçek zamanlı, yaratıcı ve detaylı tarifler üretir.
- **Görsel Analiz**: Malzemelerinizin fotoğrafını yükleyerek AI'ın onları tanımasını ve tarife dahil etmesini sağlayabilirsiniz.
- **Dinamik Görseller**: Başarılı tarif üretiminde kutlama konfetileri ve akıcı arka plan animasyonları ile premium deneyim.
- **Farklı Seçenekler**: Aynı malzemelerle sıkılmadan farklı pişirme teknikleri ve sunumlar içeren yeni tarifler talep edebilirsiniz.
- **İnteraktif Galeri**: Hazırladığınız yemekleri fotoğraflayıp puanlayarak topluluk galerisine (tarayıcı bazlı) ekleyebilirsiniz.
- **Modern Tasarım**: Glassmorphism estetiği, responsive (mobil uyumlu) yapı ve akıcı animasyonlar.
- **Hızlı Erişim**: Orijinal portfolyo sayfanıza tek tıkla dönüş imkanı.

## 🚀 Nasıl Çalıştırılır?

Bu uygulama tamamen sunucusuzdur. Çalıştırmak için:
1. `index.html` dosyasını herhangi bir modern tarayıcıda (Chrome, Edge, Firefox vb.) açın.
2. İnternet bağlantınızın olduğundan emin olun (Gemini API bağlantısı için gereklidir).
3. Malzemelerinizi girin veya bir fotoğraf yükleyin, ardından "🌟 Tarif Üret" butonuna basın.

## 🛠️ Teknik Detaylar

- **Frontend**: Vanilla HTML5, CSS3 (Glassmorphism), JavaScript (ES6+).
- **API**: Google Generative AI (Gemini Flash 1.5).
- **Markdown**: Tariflerin şık görünmesi için `marked.js` kütüphanesi kullanılmıştır.
- **Fontlar**: Playfair Display (Başlıklar) ve Inter (Gövde metni).

## 📁 Dosya Yapısı

- `index.html`: Ana uygulama dosyası (HTML+CSS+JS).
- `portfolio_backup.html`: Orijinal portfolyo sayfanızın yedeği.
- `yemek_tarifi.py`: Projenin orijinal Python/Gradio versiyonu.
